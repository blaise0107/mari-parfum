# MARI PARFUM — витрина

Статический сайт магазина парфюмерии. Каталог, корзина, оформление заказа,
отправка заказа менеджеру в Telegram.

## Что где лежит

| Файл | Назначение |
|---|---|
| `index.html` | Главная: полка, фильтры, реестр цен, доставка и оплата |
| `product.html` | Страница аромата: флакон, пирамида нот, выбор объёма |
| `404.html` | Обрабатывает адреса вида `/product/<slug>` |
| `assets/catalog.js` | **Сгенерирован** из `catalog.json` и `settings.json` бота. Не править руками |
| `assets/app.js` | Ядро: цены, корзина, диалоги, оформление, отправка заказа |
| `assets/home.js` | Главная страница |
| `assets/product.js` | Страница товара |
| `assets/flacon.js` | Рисует флаконы (SVG) |
| `tools/build-data.mjs` | Пересобирает `assets/catalog.js` из файлов бота |
| `tools/serve.mjs` | Локальный просмотр |

## Запуск локально

```sh
node tools/build-data.mjs     # после правки каталога или настроек
node tools/serve.mjs 4173     # http://localhost:4173
```

## Источник правды — каталог бота

Цены, промо, доставка и оплата берутся из `../catalog.json` и `../settings.json`,
то есть из тех же файлов, что читает Telegram-бот. Расхождение сайта с ботом
недопустимо: клиент увидит одну сумму, а менеджер выставит другую.

Арифметика повторяет `bot.py`:

- цена объёма = `price × ml ÷ base_ml` целочисленно;
- скидка — процент **только** от суммы товаров, доставка прибавляется после вычета;
- акция начисляется при сумме товаров от `promo.min_total`.

### Что менять и где

| Задача | Где |
|---|---|
| Добавить или изменить аромат | `../catalog.json`, затем `node tools/build-data.mjs` |
| Цены, сегменты, объёмы | `../settings.json`, затем пересборка |
| Способы доставки и оплаты | `settings.json → delivery_methods / payment_methods` |
| Акция | `settings.json → promo` |
| Телефон, менеджер, цены в шапке | `tools/build-data.mjs` (`manager`, `phone`) и тексты в `index.html` |
| Домен и контакты для поисковиков | JSON-LD в `index.html` |

В `settings.json` есть черновики способов доставки с пустым названием (`new`) —
на сайт они не попадают: `build-data.mjs` их отбрасывает.

## Фотографии

Флаконы нарисованы кодом (`assets/flacon.js`): у товаров нет своих фотографий, а
чужие снимки нельзя ни по лицензии, ни стабильно — отваливается горячая ссылка.

Когда появятся свои фото, менять нужно одно место: функцию `flacon()` в
`assets/flacon.js` — вернуть `<img>` вместо `<svg>`. Остальной код менять не
придётся: везде используется один и тот же вызов.

## Как уходит заказ

По умолчанию (без сервера) сайт собирает текст заказа и открывает чат менеджера
`@Mari13011` с уже подставленным текстом — клиенту остаётся нажать «отправить».
Рядом есть кнопка «Скопировать заказ».

Если нужен **автоматический** приём заказов без клика, поднимите приёмник на
сервернойless-хостинге (Cloudflare Workers / Pages Functions) и пропишите его
адрес в константу `ORDER_ENDPOINT` в начале `assets/app.js`:

```js
const ORDER_ENDPOINT = "https://<ваш-worker>.workers.dev/order";
```

Приёмник должен принять `POST` с JSON заказа и отправить его в Telegram через
Bot API. **Токен бота нельзя класть в клиентский JS** — он станет публичным, и
любой сможет читать переписку с покупателями и слать боту команды.
